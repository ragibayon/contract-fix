# Executable contracts
Read the host obligation and allowed parameter names. Propose only when/ensure strings.
A guard false on every observation is NOT success. Never exclude the reported input to hide a failure.
Use probe_clause before submit_clause. CHECKER_ERROR means the checker failed, not the target.
A REPAIR violation on base can be useful evidence; do not weaken the requirement to remove it.
Submission selects an executable candidate, not a proved specification. Host qualification and patch gating follow.
Use report_unsupported when required observations are outside the supported subset.
